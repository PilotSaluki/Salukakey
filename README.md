# SalukaKey

SalukaKey — утилита для macOS, которая автоматически переключает раскладку
**English ↔ Russian** во время набора и позволяет исправлять текст вручную
двойным нажатием **Shift**.

Приложение живёт в Dock и в строке меню: в Dock — иконка SalukaKey, в строке
меню — текущая раскладка (**EN** / **RU**).

---

## Возможности

- **Одиночный Shift** — переключение раскладки на следующий источник.
- **Двойной Shift** — конвертация выделенного текста или последнего слова
  между EN и RU. Повторный двойной Shift крутит слово дальше:
  `RU → EN → RU…` Выделение работает в любом месте документа.
- **Автоисправление при наборе** — если слово набрано не в той раскладке,
  SalukaKey исправляет его на лету (`ghbdtn` → `привет`, `вщп` → `dog`,
  `ерштпы` → `things`).
- **Пунктуация** — клавиши `, . ; : ' " [ ] { } / ?` корректно переводятся
  в русские буквы и обратно (`hs,f` → `рыба`, `,hfnm` → `брать`).
- **Программы исключения** — приложения, в которых SalukaKey полностью
  отключается.
- **Без файловых логов** — приложение не пишет историю ввода на диск и не
  отправляет данные в сеть.

## Установка

### Готовое приложение

1. Скачай `SalukaKey.app` со страницы релизов:
   <https://github.com/PilotSaluki/Salukakey/releases>
2. Перемести `SalukaKey.app` в папку **Applications**.
3. Открой приложение.
4. Выдай два разрешения (см. ниже) и перезапусти SalukaKey.

### Сборка из исходников

Требуются Xcode Command Line Tools:

```bash
xcode-select --install
```

Затем:

```bash
./build.sh
open SalukaKey.app
```

---

## Разрешения macOS

SalukaKey нужны **оба** разрешения:

1. **System Settings → Privacy & Security → Accessibility**  
   Добавь `SalukaKey.app` и включи переключатель.
2. **System Settings → Privacy & Security → Input Monitoring**  
   Добавь `SalukaKey.app` и включи переключатель.

После выдачи разрешений **перезапусти приложение**.

> После пересборки `.app` macOS может считать приложение новым (ad-hoc подпись).
> В этом случае удали старую запись в обоих списках, добавь `SalukaKey.app`
> заново и перезапусти.

## Меню SalukaKey

В строке меню, в меню иконки раскладки:

1. **Автоисправление текста** — только автопереключение слов при наборе.
   Двойной Shift и одиночный Shift работают независимо. Включено по умолчанию.
2. **Отключение всех функций** — отключает автопереключение и двойной Shift.
   Одиночный Shift продолжает работать. Выключено по умолчанию.
3. **Shift для смены раскладки** — переключение раскладки одиночным Shift.
   Включено по умолчанию.
4. **Программы исключения** — список приложений, в которых SalukaKey
   не перехватывает ввод вообще (включая одиночный Shift).
5. **About SalukaKey** — версия и кнопка **Check GitHub for Updates...**.
6. **Quit SalukaKey** — завершение работы.

---

## Программы исключения

Открой **Программы исключения** в меню, нажми **+**, выбери приложения
(например, терминал или игру) и нажми **Добавить**. В этих приложениях
SalukaKey не реагирует ни на автоисправление, ни на Shift.

## Приватность

SalukaKey работает полностью локально. Файловое логирование отключено,
телеметрия и сетевые запросы отсутствуют. Настройки хранятся в `UserDefaults`
macOS.

---

## Ограничения

- Однобуквенные слова (`я`, `а`, `b`, `c`) и слова, валидные в обоих языках
  (`in` / `шт`, `кот`, `key`), не автопереключаются — используй двойной Shift.
- Автопереключение рассчитано на пару **EN ↔ RU**; другие раскладки
  переключаются одиночным Shift, но без spell-check эвристик.
