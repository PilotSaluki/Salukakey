# SalukaKey

> **Мгновенное переключение раскладки на лету EN ↔ RU прямо во время набора.** 
> Больше не нужно допечатывать слово до конца и жать пробел

### ⚡ В чём главное отличие?

Большинство переключалок ждут, пока вы закончите слово и нажмёте `Space`, чтобы судорожно исправить текст. 
**SalukaKey исправляет текст в реальном времени прямо в процессе ввода.**

---

## Возможности

* **Real-time On-the-Fly Switch** — автоматическое исправление раскладки RU/EN в момент набора.
* **Двойной Shift** — быстрое ручное переключение выделенного\последнего введенного текста.
* **Строго в Menu Bar** — никакого мусора в Dock, фоновая работа с минимальным аппетитом к RAM и CPU.
* **Исключения на лету** — добавление рабочих программ и терминалов в игнор-лист в пару кликов.
* **Слова-исключения** — слова, которые никогда не автопереключаются и приводятся к заданному написанию: `азы` → `fps`, `пшерги` → `github`.
* **Privacy First** — работает локально на macOS, не логирует ввод и никуда ничего не отправляет.

## Установка

### Готовый образ (DMG)

Скачай образ и перетащи приложение в **Applications**:

[**SalukaKey-v1.2.0.dmg**](https://github.com/PilotSaluki/Salukakey/releases/latest/download/SalukaKey-v1.2.0.dmg)

1. Открой скачанный `.dmg`.
2. Перетащи **SalukaKey** в папку **Applications**.
3. Запусти SalukaKey из **Applications**.
4. Выдай два разрешения (см. ниже) и перезапусти приложение.

> **macOS предупреждает, что приложение не подписано?** SalukaKey собирается
> локально и подписывается ad-hoc подписью, поэтому Gatekeeper не доверяет
> бинарнику. Сними метку карантина:
>
> ```bash
> xattr -cr /Applications/SalukaKey.app
> ```
>
> Либо открой приложение через **правый клик → «Открыть»** и подтверди
> действие в диалоге.

### Готовое приложение (.app)

1. Скачай `SalukaKey.app` со страницы релизов:
   <https://github.com/PilotSaluki/Salukakey/releases>
2. Перемести `SalukaKey.app` в папку **Applications**.
3. Открой приложение.
4. Выдай два разрешения (см. ниже) и перезапусти SalukaKey.

### Сборка из исходников

Требуются Xcode Command Line Tools:

```bash
xcode-select --install
```

Затем:

```bash
./build.sh          # собрать SalukaKey.app
open SalukaKey.app
```

Готовый образ для установки собирается отдельным скриптом:

```bash
./make_dmg.sh       # собрать SalukaKey-v1.2.0.dmg
```

## Разрешения macOS

SalukaKey нужны **оба** разрешения:

1. **System Settings → Privacy & Security → Accessibility**  
   Добавь `SalukaKey.app` и включи переключатель.
2. **System Settings → Privacy & Security → Input Monitoring**  
   Добавь `SalukaKey.app` и включи переключатель.

После выдачи разрешений **перезапусти приложение**.

> После пересборки `.app` macOS может считать приложение новым (ad-hoc подпись).
> В этом случае удали старую запись в обоих списках, добавь `SalukaKey.app`
> заново и перезапусти.

## Меню SalukaKey

В строке меню, в меню иконки раскладки:

1. **Автоисправление текста** — только автопереключение слов при наборе.
   Двойной Shift и одиночный Shift работают независимо. Включено по умолчанию.
2. **Отключение всех функций** — отключает автопереключение и двойной Shift.
   Одиночный Shift продолжает работать. Выключено по умолчанию.
3. **Shift для смены раскладки** — переключение раскладки одиночным Shift.
   Включено по умолчанию.
4. **Программы исключения** — список приложений, в которых SalukaKey
   не перехватывает ввод вообще (включая одиночный Shift).
5. **Слова-исключения...** — список целых слов, которые не автопереключаются
   и служат целью исправления при наборе в другой раскладке.
6. **About SalukaKey** — версия и кнопка **Check GitHub for Updates...**.
7. **Quit SalukaKey** — завершение работы.

---

## Программы исключения

Открой **Программы исключения** в меню, нажми **+**, выбери приложения
(например, терминал или игру) и нажми **Добавить**. В этих приложениях
SalukaKey не реагирует ни на автоисправление, ни на Shift.

---

## Слова-исключения

Открой **Слова-исключения...** в меню и добавь слова кнопкой **+**
(например, `github`, `fps`). Список сохраняется в `UserDefaults`
в нижнем регистре.

- **Правильное слово не трогается:** `fps`, набранный в EN, остаётся `fps`.
- **Ошибочная раскладка исправляется:** если слово целиком переводится
  в слово из списка, SalukaKey подставляет его и переключает раскладку:
  `азы` → `fps`, `пшерги` → `github`.
- **Только целое слово:** `базы`, `вазы`, `фазы` не совпадают с `азы`
  и остаются без изменений.
- **Двойной Shift** сразу после такого исправления возвращает исходное
  слово и не переводит его повторно.
- **Автопополнение:** три одинаковых ручных исправления двойным Shift
  (`пшерги` → `github`) добавляют итоговое слово в список автоматически.

## Приватность

SalukaKey работает полностью локально. Файловое логирование отключено,
телеметрия и сетевые запросы отсутствуют. Настройки хранятся в `UserDefaults`
macOS.

---

## Ограничения

- Однобуквенные слова (`я`, `а`, `b`, `c`) и слова, валидные в обоих языках
  (`in` / `шт`, `кот`, `key`), не автопереключаются — используй двойной Shift.
- Автопереключение рассчитано на пару **EN ↔ RU**; другие раскладки
  переключаются одиночным Shift, но без spell-check эвристик.
